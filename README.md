# منصة الاختبارات التفاعلية المصورة للطلاب ولوحة تحكم المعلم
**Interactive Technical Quiz Platform & Teacher Database Dashboard**

منصة ويب تعليمية تفاعلية متكاملة باللغة العربية (RTL) لتقديم الاختبارات التقنية المصورة للطلاب بنظام **سؤال بسؤال (Step-by-Step)**، مع **لوحة تحكم شاملة للمعلم (Dashboard)** وإدارة مكتبة الكويزات المتعددة وقاعدة بيانات النتائج عبر **رابط موحد واحد (`/`)** بصلاحيات منفصلة.

---

## ✨ المميزات الرئيسية (Key Features)

### 1. بوابة دخول موحدة بصلاحيات منفصلة (`/`)
- **دخول الطلاب (بدون كلمة مرور):** يسجل الطالب دخوله مباشرة عبر **الرقم التدريبي/الجامعي** و**الاسم الكامل** للبدء الفوري في الكويز النشط حالياً.
- **دخول المشرف / المعلم (محمي بكلمة مرور):** يسجل المعلم دخوله من نفس البوابة الموحدة للوصول إلى لوحة التحكم، مكتبة الكويزات، وتفاصيل قاعدة البيانات.
- **سياسة المحاولة الواحدة لكل كويز:** يسمح النظام لكل رقم طالب بتقديم الكويز النشط مرة واحدة فقط؛ وعند دخوله مجدداً تظهر له نتيجته المسجلة ومراجعة إجاباته، مع إمكانية سماح المعلم له بالإعادة عبر حذف المحاولة من الداشبورد.

### 2. واجهة اختبار تفاعلية (سؤال بسؤال)
- عرض الأسئلة **خطوة بخطوة (Step-by-Step)** مع شريط تقدم، عداد زمني، وأزرار تنقل سريعة بين الأسئلة.
- **رسوم توضيحية مدمجة (Inline SVG Diagrams):** يدعم كل سؤال رسماً توضيحياً تقنياً عالي الدقة (أو يولّد النظام تلقائياً رسماً تقنياً مطابقاً لموضوع السؤال عند عدم وجود رسم مدمج).
- **توزيع متوازن للإجابات الصحيحة:** يتم توزيع موقع الإجابة الصحيحة بين الخيارات (`أ`، `ب`، `ج`، `د`) بشكل متوازن وثابت دون عشوائية متقلبة أثناء الحل.
- **إظهار النتيجة والتوضيحات في نهاية الاختبار فقط:** لا تظهر صحة الإجابة أثناء الحل، وفور التسليم النهائي يحصل الطالب على درجته، النسبة المئوية، التقدير، ومراجعة تفصيلية للإجابات مع التوضيح العلمي لكل سؤال.

### 3. إدارة الكويزات المتعددة (رفع أكثر من 20+ كويز)
- إمكانية إضافة ورفع أكثر من **20 كويز** في النظام عبر 3 طرق مرنة:
  1. **رفع ملفات (Drag & Drop):** استيراد ملفات الكويز بصيغة `.html` أو `.json` (مفردة أو دفعة واحدة).
  2. **لصق الكود مباشرة:** لصق كود HTML أو مصفوفة أسئلة JSON/JS واستخراج الأسئلة والرسوم التوضيحية تلقائياً.
  3. **الإنشاء اليدوي:** نموذج مرئي لإضافة الأسئلة والخيارات وتحديد الإجابة الصحيحة والرسوم التوضيحية.
- **تفعيل فوري لأي كويز:** يمكن للمعلم بضغطة زر واحدة اختيار أي كويز من المكتبة ليصبح هو **الكويز المتاح حالياً للطلاب**.

### 4. داشبورد المعلم ومستكشف قاعدة البيانات
- **مؤشرات الأداء (KPIs):** إجمالي المختبرين، متوسط الدرجات، نسبة الاجتياز، أعلى/أقل درجة، ومتوسط زمن الحل لكل كويز.
- **سجل نتائج الطلاب:** جدول تفاعلي مع البحث بالاسم أو الرقم التدريبي، التصفية حسب التقدير، وعرض ورقة إجابة كل طالب بالتفصيل.
- **تحليل الأسئلة (Item Analysis):** إحصائيات نسبة الإجابات الصحيحة وتوزيع اختيارات الطلاب لكل سؤال.
- **تصدير البيانات:** تصدير النتائج إلى ملف **Excel (CSV)** يدعم اللغة العربية، أو تصدير أوامر **SQL Dump** وبيانات **JSON** الخام.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الواجهة الأمامية (Frontend):** React 19, TypeScript, Tailwind CSS v4, Lucide Icons
- **الخادم الخلفي (Backend):** Node.js, Express.js, tsx
- **أداة البناء والتطوير (Build Tool):** Vite
- **قاعدة البيانات (Database):** تخزين مستندات علائقي دائم على الخادم (`data/quiz_database.json`) يحفظ الكويزات المرفوعة، الكويز النشط، وجميع محاولات الطلاب.

## 🚀 طريقة التشغيل محلياً (Getting Started)

### المتطلبات الأساسية
- **Node.js** (الإصدار 18 أو أحدث)
- **npm** أو **bun**

### خطوات التثبيت والتشغيل

1. **استنساخ المستودع (Clone Repository):**
   ```bash
   git clone <repository-url>
   cd <repository-folder>
   ```

2. **تثبيت الحزم البرمجية (Install Dependencies):**
   ```bash
   npm install
   ```

3. **تشغيل بيئة التطوير (Run Development Server):**
   ```bash
   npm run dev
   ```
   سيعمل التطبيق والخادم معاً على الرابط:
   `http://localhost:3000`

4. **بناء نسخة الإنتاج (Production Build):**
   ```bash
   npm run build
   npm start
   ```

## 🔐 صلاحيات الدخول والاسخدام (Authentication & Roles)

| نوع المستخدم | طريقة الدخول من الرابط الموحد (`/`) | الصلاحيات المتاحة |
| :--- | :--- | :--- |
| **الطالب (Student)** | إدخال **رقم الطالب** + **الاسم الكامل** (بدون كلمة سر) | تقديم الكويز المفعل حالياً (سؤال بسؤال) + عرض النتيجة النهائية ومراجعة الإجابات لمرة واحدة. |
| **المشرف / المعلم (Admin)** | اسم المستخدم: `admin`<br>كلمة المرور: `Sahar2026` | الوصول الكامل للداشبورد، رفع وإدارة أكثر من 20 كويز، تفعيل الكويز المتاح للطلاب، حذف محاولات الطلاب لإتاحة الإعادة، وتصدير النتائج (CSV / SQL / JSON). |

## 🔌 واجهات البرمجة الخلفية (API Endpoints)

| الطريقة (Method) | المسار (Endpoint) | الوصف |
| :--- | :--- | :--- |
| `POST` | `/api/auth/admin` | التحقق من بيانات دخول المشرف (`admin`) |
| `POST` | `/api/auth/student` | التحقق من رقم الطالب وحالة تأديته للكويز النشط |
| `GET` | `/api/quizzes/active` | جلب بيانات وأسئلة الكويز المفعل حالياً للطلاب |
| `POST` | `/api/quizzes` | إضافة أو رفع كويز جديد (أو مجموعة كويزات دفعة واحدة) |
| `POST` | `/api/quizzes/:quizId/activate` | تفعيل كويز محدد ليصبح هو الكويز المتاح للطلاب |
| `PUT` | `/api/quizzes/:quizId` | تعديل عنوان أو وصف كويز محفوظ |
| `DELETE` | `/api/quizzes/:quizId` | حذف كويز من مكتبة النظام |
| `POST` | `/api/submissions` | تصحيح واعتماد إجابات الطالب وحفظها في قاعدة البيانات |
| `DELETE` | `/api/submissions/:submissionId` | حذف محاولة طالب للسماح له بإعادة الاختبار |
| `GET` | `/api/dashboard` | جلب إحصائيات المعلم، الكويزات، وتحليل الأسئلة ومواصفات قاعدة البيانات |
